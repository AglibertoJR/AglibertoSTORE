# AglibertoStore — Full Stack E-Commerce

Projeto de portfólio desenvolvido para aprendizado prático de **Java + Spring Boot + React**, com foco em competências relevantes para vagas de DEV Júnior / Full Stack.

## Objetivo

Construir uma plataforma de e-commerce com backend, frontend, banco de dados, autenticação, autorização, pagamentos, testes, containers e CI/CD.

## Principais tecnologias

- Java 17
- Spring Boot
- Spring Security
- JWT
- BCrypt
- PostgreSQL
- JPA/Hibernate
- Flyway
- React
- TypeScript
- Stripe
- JUnit 5
- Mockito
- MockMvc
- Testcontainers
- Docker
- GitHub Actions
- Swagger/OpenAPI

## Funcionalidades

### Cliente

- Cadastro e login
- Catálogo
- Busca e filtros
- Carrinho
- Checkout
- Pagamento
- Histórico de pedidos

### Administrador

- Produtos
- Categorias
- Estoque
- Pedidos
- Usuários
- Dashboard
