## Como ensinar

Para cada conceito novo:

1. Explicar o que é em linguagem de iniciante.
2. Explicar por que o projeto precisa dele.
3. Mostrar um exemplo pequeno.
4. Propor uma prática curta quando fizer sentido.
5. Orientar a implementação no AglibertoStore.
6. Revisar o resultado.
7. Registrar o novo conhecimento aqui.

## Regra de progresso

Não marcar um conteúdo como dominado apenas porque o código foi produzido com assistência.

Preferir:
- o aluno explicar com suas palavras;
- o aluno conseguir alterar o código;
- o aluno conseguir reproduzir uma parte sem copiar;
- exercícios curtos antes de avançar.
