# AglibertoStore — Decisões Técnicas

Este arquivo registra decisões relevantes e o motivo delas.

| ID | Decisão | Motivo | Status |
|---|---|---|---|
| ADR-001 | Usar Java 17 | Alinhamento com o ambiente de estudo atual e ampla adoção em projetos Spring | Definida |
| ADR-002 | Usar Spring Boot | Stack principal para Java backend e APIs REST | Definida |
| ADR-003 | Usar PostgreSQL | Banco relacional robusto e relevante para vagas | Definida |
| ADR-004 | Usar React + TypeScript | Completar o perfil Full Stack | Definida |
| ADR-005 | Usar JWT | Demonstrar autenticação stateless em API | Definida |
| ADR-006 | Usar BCrypt para senhas | Senhas devem ser armazenadas como hash, não como texto puro | Definida |
| ADR-007 | Usar Stripe | Demonstrar integração com pagamento real/simulado em ambiente de desenvolvimento | Definida |
| ADR-008 | Usar Docker | Reproduzibilidade do ambiente | Definida |
| ADR-009 | Usar GitHub Actions | Demonstrar CI/CD básico | Definida |
| ADR-010 | Separar frontend e backend | Melhor organização e demonstração clara de arquitetura Full Stack | Definida |

## Regra

Novas decisões importantes devem ser adicionadas aqui com:
- o que foi decidido;
- por que foi escolhido;
- alternativas consideradas quando forem relevantes;
- status.
